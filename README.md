# Portfolio (Next.js + Tailwind)

Inspiriert von b-r.io. Next.js (App Router), TypeScript, Tailwind CSS v4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- Inhalte (Name, Texte, Links, Projekte, Fotos): `src/data/site.ts`
- Fotos: nach `public/photos/` legen, Pfad in `site.ts` eintragen
- Komponenten: `src/components/`, Seiten: `src/app/`
